# Архитектура проекта

## 1. Структура проекта
Проект разделен на две папки:
1. **`ui-library`** — библиотека. Здесь хранятся только визуальные элементы (кнопки, игровое поле, панель управления). Она не знает правил игры.
2. **`frontend`** — основное приложение. Здесь хранится логика игры (кто ходит, кто победил) и страницы сайта. Оно использует элементы из `ui-library`.

## Структура папок и файлов

```text

│   │   ├── main.tsx          # Точка входа в приложение
```

## 2. Используемые библиотеки
- **React** (версия 19) — для создания интерфейса (кнопок, полей).
- **React Router** (версия 7) — для переключения между страницами (переходов).
- **Vite** (версия 7) — сборщик (программа, которая запускает проект).
- **TypeScript** (версия 5.9) — язык программирования (JavaScript с типами).
- **Jest** (версия 30) — для тестирования кода.

## 3. Компоненты библиотеки (`ui-library`)
- **`Button`** — обычная кнопка.
- **`GameBoard`** — игровое поле (сетка 3х3).
- **`GameControls`** — панель управления (выбор сложности, кнопки "Новая игра" и "Сдаться").

## 4. Страницы приложения (`frontend`) и маршруты
Приложение использует React Router. Вот маршруты:
- **`/`** — Главная страница (приветствие и кнопка "Начать игру").
- **`/game`** — Страница игры (где находятся `GameBoard` и `GameControls`).
- **`/rules`** — Страница правил (текст о том, как играть).

## 5. Как связаны проекты
Приложение `frontend` подключает `ui-library` и берет оттуда компоненты. Например, на странице `/game` отображаются компоненты `GameBoard` и `GameControls` из библиотеки.
